# NEXAH Control Portal

The NEXAH Control Portal is a public, read-only projection of selected NEXAH
Mission Control, A0 Science Desk, and B0 Builder Deck surfaces.

It provides no write route, control authority, scientific activation,
publication approval, or replacement for the owning source repositories. The
exact source revisions and projection boundary are recorded in
[`portal-manifest.json`](portal-manifest.json).
