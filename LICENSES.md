The Control Portal is a mixed-material, public read-only projection. Rendering,
copying, indexing, or publishing a source-bound projection does not transfer
source authority or replace the source artifact's license.

| --- | --- | --- |
| Root portal shell (`index.html`, `portal.css`, `portal.js`, `public-cut.js`) and portal-specific automation | [Apache 2.0](LICENSE) | Original implementation authored specifically for this portal unless a file states otherwise |
| Original portal documentation and interface text | [CC BY 4.0](LICENSE-DOCS.md) | Original portal-specific prose unless a file states otherwise |
| `portal-manifest.json` release and provenance metadata | [CC0 1.0](LICENSE-DATA.md) | Original manifest metadata only; references do not relicense their targets |
| `00 EXECUTIVE/NEXAH-Mission-Control/**` | Owning source terms and publication boundary | Public-safe projection only; the private Mission Control repository and non-projected contents are not open-licensed by this repository |
| `10 NEXAH CORE/NEXAH/**` | Owning NEXAH Core licenses and provenance | Projection does not change source authority or licensing |
| `30 SCIENCE LAB/NEXAH-Science-Lab/**` | Owning Science Lab licenses and provenance | Projection does not change evidence state, lifecycle, claim boundary, source authority, or licensing |
| Third-party or source-derived material | Its stated source terms | Not relicensed by the portal |

If a projected artifact lacks an explicit compatible reuse right, public access
through this portal should not be interpreted as permission to redistribute or
adapt it.

Licensing does not grant control authority, activate research, approve
publication, or permit a modified distribution to present itself as an
official NEXAH control surface. See [NOTICE](NOTICE) and
[TRADEMARKS.md](TRADEMARKS.md).
